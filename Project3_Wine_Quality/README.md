# Wine Quality Exploratory Data Analysis

## Objective
Explore the factors affecting wine quality using exploratory data analysis.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
WineQT.csv

## Tasks
- Data Exploration
- Descriptive Statistics
- Correlation Analysis
- Outlier Detection
- Filtering and Sorting
- Data Visualization

## Conclusion
This project analyzes wine quality and identifies the factors that influence the quality of wine.
