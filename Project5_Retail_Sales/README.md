# Retail Sales Analysis Dashboard

## Objective
Analyze retail sales data and generate business insights using Exploratory Data Analysis (EDA).

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Global_Superstore2.csv

## Tasks
- Data Cleaning
- Sales Analysis
- Region-wise Analysis
- Category-wise Analysis
- Statistical Analysis
- Data Visualization

## Conclusion
This project analyzes retail sales data, identifies sales trends, and provides business insights using EDA techniques.
