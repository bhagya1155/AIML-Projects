# Titanic Data Cleaning & Passenger Analysis

## Objective
Analyze passenger survival trends using the Titanic dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Titanic-Dataset.csv

## Tasks
- Data Cleaning
- Missing Value Handling
- Outlier Detection
- Filtering and Grouping
- Data Visualization
- EDA Report

## Conclusion
This project analyzes passenger information and survival trends using exploratory data analysis.
