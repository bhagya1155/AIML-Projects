# Diamond Price Analysis

## Objective
Analyze how different features influence diamond prices using Exploratory Data Analysis (EDA).

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
diamonds.csv

## Tasks
- Data Cleaning
- Missing Value Handling
- Outlier Detection
- Statistical Analysis
- Correlation Analysis
- Data Visualization

## Conclusion
This project analyzes the factors affecting diamond prices and provides insights using EDA techniques.
